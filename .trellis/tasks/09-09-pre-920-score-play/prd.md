# 9/20 前提交：要交给评委什么

截止时间：2026 年 9 月 20 日。官方竞赛规则优先于本仓库本地文档。

2026 年 9 月 10 日已确认：点表和阈值由上位机批量写入，固件不内置演示点表。工作顺序：先 `09-10-host-nsh-vgpoint` 把点表写到板端并让采集改读已确认表，再 `09-09-demo-threshold-alarm` 告警上屏，再限时试验带屏固件上的 Agent。

## 目标

在截止日期前提交一套评委能看懂、能复现的作品：

- 点表来自上位机；开发板上能看到按该表触发的本地告警（不插网线也行）
- 演示视频里能看到 Agent 真正调用工具并给出自然语言结果
- 技术难度用已经提交的公共仓库改动说明

## 现状（2026 年 9 月 10 日核对）

官方评分：技术难度 30、产品创新 20、项目完整度 20、AI 开发 10、商业潜力 10、展示效果 10。

已经具备：H750 上的板载 Agent、两份运营技能文件、一次定时日报、Modbus 扫描、带屏界面、自然语言查数、7 个公共仓库 Pull Request。

还缺：

- 运行时点表（含比较方式和阈值），由上位机写入 eMMC，采集和告警读这张表
- 屏幕侧仍用编译进固件的组态数组做周期采集，并用点名称判断水浸和烟雾
- 告警发生后由 Agent 解释的上板记录
- 面向评委的 README、专属仓库合入、演示视频

带屏固件已经包含 Agent 程序。开机同时自动启动界面和 Agent 会触发断言。作品只留这一套固件，不再用无屏镜像作拍摄退路。

## 已确定的选择

1. 演示视频里必须有一次真实的 Agent 工具调用。
2. 点表和阈值由上位机批量下发；固件不预置点名和阈值。
3. 先完成按运行时点表告警上屏，再限时约 8 小时试验同一套固件上的 Agent。失败当天停止，不要改烧第二套镜像。
4. 开机不要同时自动启动人机界面和 Agent。
5. 不做周报。点表写入走板端 `vgpoint`。仓外已有 `F:\Project\uppercomputer`（PyQt，协议对齐 `docs/velaguard-host-nsh-protocol.md`），板测和演示优先用它完成试读后人确认 `apply --confirm`。竞赛仓保留 `scripts/vgpoint_host_apply.ps1` 作无人值守抽检。9/20 前不把该 GUI 收进专属仓，不新开上位机任务，不在屏上编辑点表。

## 要做到什么

1. 固件提供运行时点表（比较方式、预警值、严重值）和告警比较。没有点表时首页为空。
2. 上位机批量写入点表；候选经试读、本机确认后才生效。Agent 不能改点表。去掉按点名称判断水浸和烟雾的代码，周期采集改读运行时点表，不再读编译进固件的组态数组。
3. 按已生效点表注入超阈值或拔从站后，告警页能看到，并写入 `/data/velaguard/pending_alarm.txt`。不依赖网络和 Agent。
4. 日报由 Agent 生成。屏幕报告页打开同一份按日期命名的日报文件。全过程不能写从站寄存器。不做周报。
5. Agent 写日报的目录和屏幕读日报的目录必须相同。
6. 对照项目手册第 14.1 节写一份演示范围说明，没做的标成后续阶段。日报的既有记录可以继续用。
7. README 写清产品说明、如何编译、如何演示、公共仓库 Pull Request 列表、赛道证据。只烧 `velaguard-lvgl`。
8. 产品代码和 AI 日志合入专属仓库的提交分支。7 个公共仓库 Pull Request 保持可打开。
9. 本任务写出 5 分钟分镜；作品介绍文档和成片由人准备。
10. 评委能看见 Agent：在同一套带屏固件上提问或出日报；做不到就用已有上板记录，并拍报告页上的既有日报。

## 四个子任务

| 子任务目录 | 做什么 |
| --- | --- |
| `09-10-host-nsh-vgpoint` | NSH `vgpoint`、COM3 上位机脚本、采集/首页改读已确认表 |
| `09-09-demo-threshold-alarm` | 按已确认表做阈值/离线告警上屏、日报目录对齐 |
| `09-09-samefw-agent-spike` | 告警上屏通过后，限时约 8 小时试验带屏固件启动 Agent |
| `09-09-judge-submit-pack` | README、手册对照、分镜、合入前提醒 |

父任务不写产品代码。批准规划后，启动通信子任务，不要把父任务标成进行中。不要再平行做第三套点表写入。

## 本次不做

- 开机同时自动启动人机界面和 Agent
- 限时试验失败后继续改内部静态内存，或打开带屏固件里已关闭的心跳
- 把仓外上位机收进专属仓、新开上位机功能、在屏幕上编辑点表
- 故障规则库、固件在线升级、周报、云端桥接、全波特率扫描
- 语音、板端大模型、完整趋势页和诊断页
- 为了加分再开新的 NuttX 驱动 Pull Request
- 把 Cursor 会话日志改标成其他工具名称

## 怎样算完成

- [ ] 上位机批量写入并确认后，首页出现这些点；采集不再使用编译进固件的组态数组
- [ ] 不插网线也能在告警页看到超阈值或离线，并且磁盘上有待处理告警文件
- [ ] 屏幕报告页能打开 Agent 写入的那份日报（目录已对齐）
- [ ] 视频或上板日志里有一次 Agent 工具调用（同一套 `velaguard-lvgl`）；没有写寄存器
- [ ] 带屏固件试验有书面结论（做成或做不成）。做不成也不改烧第二套固件，不再加时
- [ ] README 评委大约 5 分钟能读完；手册对照和分镜对得上真实画面
- [ ] 专属仓库可以合入提交分支；提交清单里仓库内的项目已勾选或标明谁来执行
