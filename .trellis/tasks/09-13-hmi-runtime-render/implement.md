## 验证矩阵

| 场景 | 断言 |
|---|---|
| 200 次切页 | 相同页面资源回到基线，无失效指针 |
| 慢读报告 + 离页 + 返回 | 没有旧页回写，读取/生成请求仍一致 |
| 同一 ID 的同值新样本 | 历史前进且只应用一轮 |
| 同数量换 ID/改名/最长 ID 尾项变化 | 列表、下拉和关联信息更新 |
| 消费期间新点表发布 | 旧代次不能写入新下标 |
| 单点失败、恢复、32 点混合 | 规则与去重不变 |
| 清文件迟到 + 新告警 | 新告警最终保留，旧请求不标为新请求完成 |
| 存储失败/worker 启动失败 | UI 继续工作，有错误状态，无虚假落盘 |
