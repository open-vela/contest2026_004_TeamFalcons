# 带屏固件上延迟启动 Agent（限时约 8 小时）

所属父任务：`09-09-pre-920-score-play`。

前置：`09-09-demo-threshold-alarm` 已在开发板上通过。当天做不成就停止，不要隔夜继续改。

## 目标

确认带屏固件在人机界面已经运行之后，再启动 `ai_agent --daemon` 能否保持整机可用，并完成一次评委能看懂的提问或日报。做不到就停，不要改烧第二套固件。

## 要做到什么

- 不要在开机时同时自动启动人机界面和 Agent
- 不要打开带屏编译里已经关掉的定时任务和心跳
- 失败后不要继续改内部静态内存布局
- 做成的标志：系统日志出现 `Agent loop started (HMI fixed buffers)`；提问时有工具调用；没有写寄存器
- 做不成：写清现象（是否断言、是否像堆查询触发的问题、是否栈不够）。分镜仍只烧这一套，用已有日报和上板记录

## 怎样算完成

写成或写不成都算本任务结束。

- [ ] 有一页书面结论
- [ ] 做成：带屏固件上能提问或写出日报，报告页不是空白
- [ ] 做不成：书面结论写清；视频不改烧无屏固件（沿用 2026 年 8 月 30 日的日报记录）

## 本次不做

把带屏 Agent 当成截止日期前的主线长期去磨。不要恢复开机同时自动启动这两项。
