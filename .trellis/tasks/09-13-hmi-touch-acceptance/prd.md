# HMI 触摸交互与整体验收

## Goal

在前两个子任务的可测量、资源正确的 UI 上改善触摸跟手性、滚动防误触和返回连续性，完成同固件的最终性能与安全回归。

父任务：`09-13-hmi-ux-performance`。本任务当前只有文档，不包含已实施优化或验收成绩。

## Background

父任务证据 E01/E06/E07 说明主循环休眠和触摸读取需分开设置并实测；E22/E23 说明动态告警数组下标与紧凑热区需要明确交互策略。此前页面重建会丢失滚动和趋势窗口，本任务使用子任务 2 的稳定根和模型版本补齐状态恢复。

## Requirements

| 编号 | 要求 |
|---|---|
| T-R1 | 输入及时处理，按下反馈不等待业务 tick 或后台文件完成 |
| T-R2 | 使用 LVGL 原生滚动，拖动/惯性结束不触发按钮和告警操作 |
| T-R3 | 按下期间点位重排、恢复、删除或新告警期开始，不能把操作转给其他目标 |
| T-R4 | 返回恢复有效点位、筛选、滚动和趋势窗口；失效点位有确定行为 |
| T-R5 | 可点击范围清晰、布局稳定、文字不重叠，状态栏保持紧凑 |
| T-R6 | 报告读取/生成忙状态即时可见且可离页，重复点击不重复执行 |
| T-R7 | 完成统一性能门槛和同固件业务回归，失败明确归因，不通过缩减负载达标 |

## Acceptance Criteria

| 编号 | 验收 | 对应需求 |
|---|---|---|
| T-AC1 | `lv_indev` 读取周期为 10 ms，主循环休眠限制在 1..10 ms；显示仍 16 ms，业务 tick 仍 1000 ms | T-R1 |
| T-AC2 | 点击、长按后滑动、快速反向滚动、惯性点停和连续点击均无误操作 | T-R2 |
| T-AC3 | 告警重排、按下目标恢复/删除、同 ID 新告警期和表代次变化用例均取消失效操作 | T-R3 |
| T-AC4 | 首页到详情/趋势往返、筛选内返回、报告返回恢复正确；扫描开关不因缓存自动开启 | T-R4 |
| T-AC5 | 内容按钮触高 >=36 px、宽 >=40 px；顶部热区按设计的独立例外校验，无热区或文字重叠 | T-R5 |
| T-AC6 | 异步操作正确显示忙/结果/错误，离页不发生旧回调或重复请求 | T-R6 |
| T-AC7 | 父任务 HMI-AC1 至 HMI-AC9 全部有真实证据，尤其触摸 P95 <=100 ms、切页 P95 <=200 ms、滚动 >=30 FPS | T-R7 |
| T-AC8 | 无头/host_tests/构建/板测完成，200 点击、200 切页和 30 分钟资源记录可复查 | 全部 |

## Blocked by

以下是未来启动和完成条件，不表示前置任务已经通过。创建本包时前两项同样处于 `planning`。

- `09-13-hmi-performance-baseline` 须先交付可复现基线。
- `09-13-hmi-runtime-render` 须先通过生命周期、异步接口和完整快照回归，完成接口交接。
- 用户另行授权本子任务实施。
- L3 真实 Agent 压力验收必须解决或排除 `09-12-heartbeat-llm-round-system-wedge` 在目标固件中的影响；缺少该证据不能关闭本任务和父任务。

## Out of Scope

重新设计视觉主题、全屏页面动效、手写触摸驱动、多指手势、增加页面或业务动作、改变确认权限、系统 tick/时钟/缓存调优、告警分页或扩大容量。
