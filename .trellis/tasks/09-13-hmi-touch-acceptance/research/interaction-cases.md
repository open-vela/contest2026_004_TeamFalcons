# 交互回归用例

本清单交给实施 Agent 扩展前置无头 harness。无头已落地子集见 `interaction_check` 与 `final-results.md`；其余仍待实现/板测。

## 驱动方式

使用真实 pointer indev 输入按下、移动、保持、释放序列；固定时间步长且允许插入模型更新、后台结果与切页。优先按对象角色/点位 ID 找控件，再取得坐标，避免全部写死像素位置。

至少一组测试使用真实 press/release 事件链，不允许全部直接调用业务 handler。

## 真机补充

无头测试无法验证电容触摸采样、真实手指滑动阻力感或面板扫描。因此 I01-I09、I14-I16 还需在板端实际操作，延迟和帧率遵循父任务统一契约。

遇到断触时先记录原始输入状态和 UI 事件链，不直接改 FT5x06 频率、I2C 频率或中断引脚。必要的硬件修改要重新走原理图核查和范围批准。
