# 点表数据趋势页恢复与增强

## Goal

让实时趋势页真正可用：解除阶段 2 导航门禁，页内可直接选择点位并看清当前看的是哪个点，窗口标签与板上实际采样节奏一致，无阈值点位也能正常绘图，板上历史深度足以支撑有意义的趋势观察。

## Requirements

1. 导航：趋势页从阶段 2 门禁中移出，首页趋势快捷方式与设备页查看实时趋势按钮可直接进入；其余 Defer 页（诊断/日志/系统/添加/OTA）门禁保持不变。
2. 点位切换：趋势页头部提供下拉选择器，列出当前采集表全部点位；选择即切换图表数据源，并与全局选中点位联动（设备页按钮进入时仍落在同一点位）。
3. 点位名称：页内始终显示当前查看的点位名称；点位以 id 为键（name 可能重复或含 UTF-8，不作为查找键）。
4. 窗口语义：两个窗口按钮改为按样本数标注（最近60点 / 全部）。板上样本随完成的轮询轮次到达，间隔随点位数浮动，按时间标注不准确；模拟器 1 Hz 下 60 点即 1 分钟，语义自然成立。
5. Y 轴量程：有预警/严重阈值的点位沿用阈值定界；无阈值点位（has_warn/has_crit 为 0）按窗口内历史数据 min/max 加边距自适应，避免数据画出界。
6. 历史深度：板上 VG_HISTORY_LEN 16 到 128，模拟器维持 300；更新 vg_model.h 中已过时的 stage-2 延期注释，写明 BSS 实测增量与决策依据。
7. 离线表现：点位离线时数值显示 --，图表保留最后样本，不伪造数据（对齐 AGENTS.md V2）。

## Constraints

- 改动全部位于竞赛仓（gui/main/ui 与任务文档），不触碰公共树、defconfig 与点表协议，host_tests 无协议级变更。
- 保持 vg_page_trend.c 现有 4 series 绘制顺序与 chart_draw_task_cb 的 LVGL 9 逐系列样式机制不变。
- 分支上另有 09-13-field-test-fixes-0913 与 09-13-alarm-page-multi-rows 的在途未提交改动（vg_model.c、vg_ui_backend_board.c、vg_page_alarm.c 等与本任务部分同文件）；本任务不代提交、不回退他人改动，最终提交仅选择性暂存本任务文件。
- 本期不做：历史落盘 /data、逐样本时间戳、多点同屏叠加、诊断/日志等页解锁。

## Acceptance Criteria

- [ ] AC1 首页趋势快捷方式与设备页查看实时趋势按钮均可进入趋势页，无阶段 2 提示。
- [ ] AC2 页内下拉列出全部点位，选择后图表立即切换为该点位数据；从设备页按钮进入时落在该设备点位。
- [ ] AC3 页内显示当前点位名称；点位显示与切换均按 id 定位。
- [ ] AC4 窗口按钮标注为最近60点 / 全部，切换即时生效；模拟器上 60 点窗口与 1 分钟等价。
- [ ] AC5 无阈值点位图表完整显示数据曲线（min/max 自适应量程）；有阈值点位仍显示预警/严重阈值线。
- [ ] AC6 板端构建 BSS 增量与 128 点历史预算一致（约 +28 KB 量级），固件正常启动，趋势页在真实点表上可用。
- [ ] AC7 离线点位进入趋势页时数值显示 --，图表无虚构数据。
