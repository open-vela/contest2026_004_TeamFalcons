# 评委材料：README、分镜、合入提醒

所属父任务：`09-09-pre-920-score-play`。

带屏 Agent 做成还是做不成，会决定 README 和分镜怎么写。等那次试验有结论再收口文档。

## 目标

让评委大约 5 分钟能看懂：产品是什么、怎么编译、怎么演示、Agent 跑在同一套固件上、公共仓库的改动在哪里。成片由人拍摄。本任务写分镜和口播要点。

## 要做到什么

- README 包含产品说明、编译命令、与实际情况一致的演示步骤、7 个公共仓库 Pull Request 的链接、赛道证据表
- 对照项目手册第 14.1 节列出演示范围，没做的标成后续阶段
- 分镜对照推进方案第 11 节；拍不到的段落改成实际能拍的，不要写成没发生过的画面
- 提醒准备作品介绍文档、不超过 5 分钟的视频、专属仓库合入提交分支
- 校验 AI 日志目录；不要改会话文件正文

## 本次不做

新功能、亲自拍成片、再向公共仓库开新的 Pull Request。

## 怎样算完成

- [ ] README、分镜和带屏试验的结论互相一致
- [ ] 手册对照笔记放在本任务目录或 `docs/`
- [ ] 提交清单里仓库内的项目已勾选，或写明需要你本人执行的合入步骤
