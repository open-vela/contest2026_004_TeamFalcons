# HMI 性能基线与测量工具

## Goal

为后续两个实施 Agent 提供同口径、可重复的性能证据和测试入口。只增加观察能力和测试设施，不提前修改页面行为或性能参数。

父任务：`09-13-hmi-ux-performance`。本任务创建时只有规划文件，尚未实现统计或采集数据。

## Background

依据父任务 `research/current-state.md` 的 E01-E09、E23-E25：板端已有双缓冲和 16 ms 刷新配置，主循环按 LVGL 返回值休眠，系统 tick 为 10 ms；PC 模拟器与板端配置不同。现有无头代码能驱动点击，但还没有统一的独立构建和长时间资源验证入口。

## Requirements

| 编号 | 要求 |
|---|---|
| B-R1 | 能读取 UI 循环、输入回调、模型 tick、渲染、提交及导航分段耗时，不触发业务动作 |
| B-R2 | 统计可在构建时关闭，运行开销和存储有上限，不逐帧写日志或文件 |
| B-R3 | 有独立无头构建入口，复用实际 UI 和现有告警/趋势测试，输出确定性截图和断言 |
| B-R4 | 保存优化前当前点表、32 点容量及主要负载的测量，真实失败不隐藏 |
| B-R5 | 明确软件阶段计时、面板显示、近窗样本和整组 P95 的区别 |
| B-R6 | 后续 Agent 可按文档重现构建、场景和统计，不依赖临时二进制或聊天记录 |

## Acceptance Criteria

| 编号 | 验收 | 对应需求 |
|---|---|---|
| B-AC1 | `vghmi perf` 在未运行、统计关闭、统计开启状态均有明确只读输出，不启动第二个 HMI | B-R1 |
| B-AC2 | 统计热路径无动态分配、文件 I/O 和阻塞等待；存储预算、丢样计数可检查 | B-R2 |
| B-AC3 | 默认构建不启用统计，显式测量构建可启用；两者业务一致 | B-R2 |
| B-AC4 | 无头构建支持 RGB565 与 32 位两种缓冲，像素非空、字体可见、实际点击断言通过 | B-R3 |
| B-AC5 | 基线报告包含完整版本和矩阵，至少完成 L0/L1/L2 的真机原始采集；L3 若被既有缺陷阻塞，保留完整失败证据 | B-R4 |
| B-AC6 | 统计启用/关闭的同动作对照没有可识别的显著额外卡顿；可量化时附额外耗时比例 | B-R2、B-R5 |
| B-AC7 | 后续任务能直接使用新增入口、字段和测试 fixture；当前并不要求满足最终性能门槛 | B-R6 |

基线报告中性能不达标是有效结果；缺少必要基线数据不是采集成功。交付必须同时包含工具使用说明、原始证据位置和按 B-AC1 至 B-AC7 编号的结果，不能只提交新增统计代码。

## Blocked by

- 无前置优化子任务。需要用户另行授权实施。
- 真机采集需要正确的主线固件、可用板卡、合法已确认点表及拍摄条件。缺条件时先完成工具和主机检查，但不将 B-AC5 写为通过。
- Agent 负载若重现系统挂死，关联 `09-12-heartbeat-llm-round-system-wedge`，不在本任务修复 Agent。

## Out of Scope

改触摸周期、主循环休眠策略、页面生命周期、文件线程、列表更新、业务规则、公共显示驱动或系统 tick。这些优化属于后续任务或另行批准的范围。
