# LVGL HMI 体验与性能优化

## Goal

让现场人员在 STM32H750B-DK 的 480x272 触摸屏上更快地查看点位、切换页面和处理告警。保留现有工业风格、页面集合与安全权限，优先降低触摸延迟和长帧，避免连续操作后出现资源残留。

本父任务管理需求、任务间契约及最终集成验收。实际固件和 GUI 改动由三个子任务顺序完成，不在父任务直接实施。

## 本次授权与交接状态

- 用户已经选择性能与关键交互优化，以及跟手与稳定优先。
- 用户仅授权本轮创建详细 Trellis 任务，交给其他 Agent 实施。本轮授权不包含代码修改、任务启动、编译、烧录、提交或派发 Agent。
- 创建时所有任务保持 `planning`，未设置活动任务。后续接手者仍须取得所接子任务的实施授权，并遵循 Trellis 启动流程。
- 文档中的性能数值均为目标。当前尚无本任务采集的真机基线或验收结果。

## Background

核查基点为本仓提交 `7b7bc4b607b83394651b8c94ce35d7f0cfd7ce79`。代码证据及外部源码身份见 [现状研究](research/current-state.md)。

- 板端已经采用 RGB565、LTDC 双缓冲和 LVGL DIRECT 绘制，配置刷新周期为 16 ms。
- 页面删除回调挂在共用内容容器上，而切页只清理其子对象；页面定时器和监听存在未随退出释放的风险。
- 首页筛选、趋势选点存在重复刷新路径；日报读取、部分告警文件操作运行在 UI 调用链中。
- 板端有效点表上限是 32；当前告警页展示上限是 8 行。模拟器容量、字体、色深与板端不同。
- 相关告警多分栏和现场问题修复已归档，应保留这些结果，不重复恢复旧实现。

## Requirements

| 编号 | 用户可观察的要求 | 负责子任务 |
|---|---|---|
| HMI-R1 | 有可重复的优化前后数据，能区分触摸、绘制、提交和真实显示延迟 | baseline |
| HMI-R2 | 按下操作及时有视觉反馈，慢操作不能阻塞返回或滚动 | runtime-render、touch-acceptance |
| HMI-R3 | 连续滚动平稳，数据刷新不造成明显停顿或位置跳动 | runtime-render、touch-acceptance |
| HMI-R4 | 反复切页不积累页面监听、定时器或失效对象访问 | runtime-render |
| HMI-R5 | 返回时恢复点位、筛选、滚动位置和趋势窗口 | touch-acceptance |
| HMI-R6 | 滚动不触发点击；告警重排或恢复时，操作不会落到另一点位 | touch-acceptance |
| HMI-R7 | 显示真实状态，不重复读取或重绘未变化内容；新历史样本不能因数值相同而不更新 | runtime-render |
| HMI-R8 | 正常采集、断网、Agent 工作期间，本地规则及人工确认边界不退化 | 全部 |
| HMI-R9 | 以现有业务容量完成验证，不将原有 8 行告警展示上限扩展为新分页功能 | 全部 |

## Acceptance Criteria

详细计时起止、样本规模、分位数及证据要求统一定义在 [性能与验收契约](research/acceptance-contract.md)，子任务不得自行改口径。

| 编号 | 完成条件 | 需求映射 |
|---|---|---|
| HMI-AC1 | 实体按下到首个可见按下反馈的 P95 <=100 ms | HMI-R2 |
| HMI-AC2 | 有效点击释放到目标页面可操作的 P95 <=200 ms；报告正文加载单独计时 | HMI-R2、HMI-R5 |
| HMI-AC3 | 连续运动窗口内真实更新帧率 >=30 FPS，更新帧间隔 P95 <=50 ms | HMI-R3 |
| HMI-AC4 | 至少 200 次点击、200 次切页及 30 分钟混合操作，无误触、断触或失效回调 | HMI-R4、HMI-R6 |
| HMI-AC5 | 同一页面静止状态下的对象、监听和定时器数量回到基线；内存无持续增长 | HMI-R4 |
| HMI-AC6 | 返回状态、动态告警目标、异步结果生命周期的无头回归通过 | HMI-R5、HMI-R6 |
| HMI-AC7 | 当前点表和 32 点容量场景均完成验证，覆盖最多 8 行告警展示 | HMI-R9 |
| HMI-AC8 | 采集、历史更新、离线判定、阈值规则、主告警文件和人工确认流程通过兼容回归；不得为达到帧率降低这些功能的频率 | HMI-R7、HMI-R8 |
| HMI-AC9 | 同一主线固件完成有网、断网、Agent 工作场景验收；未通过或无法测量的场景明确保留，不以模拟器代替 | HMI-R1、HMI-R8 |

## Out of Scope

- 页面重设计、增加导航层级、日志/诊断/系统/OTA 等延期页面解锁。
- 点表屏上编辑、自动确认、自动扫描、总线排障或 Agent 写权限。
- DMA2D 新接入、LVGL 升级、显示时序或时钟调整、缓存策略修改、外设超频。
- 增大点表或历史容量、扩展告警分页、改变比较规则或离线失败窗口。
- 改变 AI 请求链路、增加声音功能、通过停掉 Agent 或遥测取得产品性能成绩。

## 完成与中止规则

测量工具完成不等于性能目标完成。若范围内优化仍不达标，提交证据、剩余瓶颈及建议，不降低标准，不直接扩大到公共驱动修改。缺少真机证据时，父任务保持未完成。
