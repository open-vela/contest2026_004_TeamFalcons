# 02: 固件版本、槽位与安全重启

**What to build:** 设备有单一固件版本来源和明确的启动槽位身份。状态、屏幕和后续 OTA 协议使用同一版本字符串；A 镜像和 B 镜像分别链接到各自槽位地址并带槽位标记；OTA 可以请求一次安全重启，重启后版本和槽位显示一致。此票作为后续 OTA 行为的身份基础，不引入 OTA 下载或安装。

**Blocked by:** 无，可以立即开始。

**Status:** ready-for-agent

- [ ] 状态和屏幕显示同一固件版本字符串和当前启动槽位。
- [ ] 构建脚本可以产出 A 和 B 两个镜像，链接地址和槽位标记正确。
- [ ] 状态载荷、屏幕和后续 OTA 协议不再各自维护硬编码版本。
- [ ] OTA 可请求安全重启，重启后版本和槽位显示与重启前一致。
- [ ] 非 OTA 场景的原有启动、采集、告警和界面行为不回归。
- [ ] 主机测试或构建检查覆盖版本字符串、槽位标记和 A/B 镜像元数据。
