# 09: 断线、重放与容量压力下保持配置一致

**What to build:** 通信、界面和持久化联通后，板端在断网、重连、重复消息、队列耗尽和资源峰值下继续遵守会话与版本规则；云端只能依据真实板端结果判断配置状态。

**Blocked by:** 06, 重启后核对提交结果; 07, 通过专用 MQTTS 操作配置会话; 08, 板端查看依据并人工确认添加.

**Status:** ready-for-agent

- [ ] 断线使未提交确认失效，重连只查询对账，不自动重放 open、put 或确认；提交中的连接变化不打断已开始的本地提交。
- [ ] 相同请求重发、异内容冲突、缓存回收后重放及延迟消息均不能重复落盘、弹窗或提交。
- [ ] 测量 TLS、MQTT 缓冲、候选解析、冻结目标、界面快照和线程栈的资源峰值，队列满和超预算时整批拒绝。
- [ ] 实际能力与目标预算不符时同步协议、云端限制和设备快照，只报告已验证容量。
