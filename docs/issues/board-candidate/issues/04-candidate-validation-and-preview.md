# 04: 下发候选并生成可确认版本

**What to build:** 云端在活动会话中下发完整候选，板端严格校验后生成包含测点和手册依据的不可变确认版本；无效候选整批拒绝，新版本使旧确认立即失效。

**Blocked by:** 03, 建立、查询和取消配置会话.

**Status:** complete

- [x] 完整性摘要按原始候选字节核对，非法 JSON、重复键、未知字段、非法编码、越界数值和摘要不符均不进入候选处理。
- [x] 地址换算、手册依据、类型、倍率、ID 与地址冲突、从机地址和 32 点合并容量全部由确定性代码校验。
- [x] 合法候选生成协议定义的确认版本及摘要，新版被受理后旧版本和旧确认不再可用。
- [x] 测试覆盖有效、单点失败整批拒绝、重复与乱序、来源不足、容量边界，以及确认前不发送新增 Modbus 请求。
