# 08: 板端查看依据并人工确认添加

**What to build:** 校验通过的候选在板端显示测点、版本和手册依据，用户可直接取消或确认添加；确认后候选进入正常采集。告警来到时确认界面让位，用户返回时只看到仍然有效的版本。

**Blocked by:** 05, 确认后提交指定版本.

**Status:** complete

- [x] 候选校验通过后才显示本地确认界面，内容与当前确认版本、来源和摘要一致。
- [x] 真实本地用户确认触发指定版本提交，取消、断线、过期或告警抢占使待确认内容失效。
- [x] 告警恢复前重新核对租约、连接、版本和绑定，告警期间排队的旧点击不能提交。
- [x] 板端不增加远程进度、等待或结果页；测试和界面证据证明旧按钮、连点与失效版本不会误应用。

验证记录：

- 主机完整测试通过，覆盖精确版本提交、取消、过期、连点、告警抢占和旧动作失效。
- 无界面 UI 测试 7/7 通过，确认页能展示测点与手册证据，并在告警时关闭、告警解除后恢复同一有效版本。
- A/B 固件均构建通过，SRAM 使用 388608/524288 字节，占 74.12%。
- 确认界面显示快照为 13952 字节；冻结候选仍由配置服务单独持有，未在界面侧重复保存。
- 本轮不包含 MQTTS、云端请求入口和真实 Broker 验收，这些属于后续网络工单。
