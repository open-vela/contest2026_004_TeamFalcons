# 02: 查询设备能力与当前配置

**What to build:** 云端可以查询一台板端实际可用的配置能力、当前运行表摘要、点位数量和从机地址、剩余容量以及当前占用状态；空表与损坏配置得到不同结果。

**Blocked by:** 01, 统一配置入口互斥.

**Status:** complete

- [x] 设备查询返回协议定义的能力、基础表摘要、点位信息、当前配置状态和启动/连接身份。
- [x] 清空配置可安全查询，文件损坏、存储不可达或内存与持久化不一致明确报告不可用。
- [x] 返回能力来自实际有效预算，超长响应有界处理，不截断能力或点位后伪装成完整结果。
- [x] 测试覆盖空表、正常表、损坏表和入口占用，查询不创建会话、不访问 Modbus、不改变运行表。
