## 重新生成

工作区 `F:\Documents\velaguard作品提交\build\final-defense-20261105-claude-v3-industry`：

```bash
python3 deckgen.py
```

然后用 ppt-master 的 `svg_to_pptx.py` 以 `authoring-svg-flat` 导出 flat 结构，
`--primary-language zh-CN`，带 notes。再用 `build/claude-defense-3styles-20261105/embed_fonts.ps1`
嵌入 MiSans 字体。改文案只需改 `deckgen.py` 里的常量，重新生成 SVG 与 PPTX。
