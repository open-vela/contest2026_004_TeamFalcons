# 80 秒真机演示分镜（对应第 14 页）

## 成片规格

| 项 | 要求 |
|---|---|
| 画幅 | 1920×1080，30 fps，横屏 |
| 时长 | 80 秒，误差不超过 1 秒 |
| 机位 | 主机位俯拍网关、扩展板、模拟从站和 RJ45，三脚架固定，全程不动 |
| 声音 | 旁白单独录，设备播报收原声，整体响度一致 |
| 输出 | MP4，H.264，AAC |
| 用途 | 嵌入第 14 页，前面留 4 秒口播，视频旁白承担本页讲解 |

先完整录 3 到 5 分钟，再剪到 80 秒。只允许对模型等待段做加速，加速处用字幕标出真实耗时。

## 四格与七段对应

第 14 页右侧四格是四个界面，视频按操作顺序拍七段：

| 四格 | 对应片段 | 时间 |
|---|---|---|
| 首页 | 全景与上电、在线点位刷新、越限与告警 | 00–28 |
| 告警详情 · AI 建议 | Agent 解释 | 28–45 |
| 运行报告 | 打开日报 | 45–57 |
| 自然语言问答 | 按键提问 | 57–70 |
| 云端管理端 / 板端确认 | 手册解析与点表下发 | 70–80 |

## 拍摄前检查

- [ ] `bash scripts/build.sh` 编译 `velaguard-lvgl`，烧录后冷启动，确认 NSH、`vghmi: autostart ok`、`vgagent: ai_agent autostart ok` 三行齐全。
- [ ] `vgprovision status` 有效；`config_show` 里的 LLM Host、Path、Model 与实际服务一致；`net_test` 通过。
- [ ] 点表已确认，14 个点位的名称、单位、阈值和在线状态与画面一致；记录点表版本。
- [ ] 回风温度严重阈值 80.0 ℃，模拟从站能把读数稳定推到 83.2 ℃。
- [ ] RS485 总线上只有板端一个主站；主机侧组态软件和轮询先停掉。
- [ ] 关闭会抢占串口的监视器；需要终端画面时单独录屏，不占用板端调试串口。
- [ ] 云端管理面板服务就绪，准备好测试用从机 PDF 手册（如智能电表说明书）及从机地址。
- [ ] 板端 MQTT 候选通道订阅正常，接收候选点表后能正常触发确定性校验与确认提示框。
- [ ] 屏幕亮度固定，避开反光；桌面只留网关、扩展板、从站和线缆。
- [ ] 清理通知和无关窗口；终端与面板不出现完整凭据、MQTT token、设备 UID 和私钥。

## 拍摄要点

- 00–06 先拍 3 秒空镜再上电，保留屏幕点亮过程。
- 06–16 两次读数刷新之间至少停 5 秒，手指不要遮挡点位。
- 16–28 保留阈值跨越的瞬间，告警页停 3 秒再切。
- 28–45 模型等待可以加速，字幕写真实耗时；工具调用只拍只读工具，出现写操作说明固件或提示词不对，停拍排查。
- 45–57 报告页内容要能看清，页面名称用运行报告或日报，不使用旧的项目代号。
- 57–70 只拍按键触发，不引入唤醒词，不拍持续监听；设备播报收原声，网络慢时保留等待动画，不剪成瞬时。
- 70–80 前半段录屏或特写管理面板上传 PDF 手册并提取点表的过程，后半段切到板端屏幕展示收到候选点表后的二次确认提示，突出“云侧只生成候选、生效权在本地”。

## 剪辑与验收

- 只做硬切，不叠假界面、不改读数、不补时间戳；字幕只做说明。
- 加速段单独标注，例如 `模型等待 12.4 s，4 倍速`。
- 旁白与画面动作对齐，设备播报不要压旁白。
- 成片试播三遍：静音看画面能否看懂，闭眼听旁白能否成立，对着第 14 页四格核对界面。
- 嵌入第 14 页后整稿试播，确认 4 秒口播、80 秒视频和翻页顺序，整场仍在 8 分钟以内。

## 素材留存

保存原片、成片、字幕文件、旁白音轨和录屏文件，记录拍摄日期、固件提交、点表版本、模型服务和台架条件。字幕里的耗时取自当次运行记录，便于答辩时核对。
