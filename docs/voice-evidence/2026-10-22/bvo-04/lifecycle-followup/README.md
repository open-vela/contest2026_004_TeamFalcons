# BVO-04 听音确认与播放、停止回归

基础播放、主动停止、重播和触摸已取得人机双方证据；轻微杂音按用户意见延后。**严格无欠载项仍未通过，不标记 BVO-04 全部完成。** 本轮不把杂音与 SAI 欠载直接认定为同一原因。BVO-03 保持未完成，没有录音回放、PDM→PCM、ASR/TTS 或语音浮层。

## 1. 人工反馈与处理

用户先确认耳机能听到声音，只有轻微杂音，影响不大、可滞后；随后确认英语 yes 可辨认、停止和重播正常。触摸最初在播放 yes 前短暂卡顿，之后恢复。更改等待与收尾后，用户确认切页正常，没有明显卡顿。

驱动原先在优先级252的播放 worker 中用 up_mdelay 忙等，结束时完整复位并重新初始化编解码器；标准音频设备最后一次 close 也调用 shutdown。这样会重复执行模拟耳机启动流程。修改为：

- 初始化延时用可调度的 nxsig_nanosleep，EINTR 按剩余时间继续；异常时保留硬件最小等待。仅任务上下文使用，中断路径不等待、不打印、不分配。
- 有本板 MCLK 生命周期回调的 WM8994 在播放完成和 shutdown 时只静音、关闭 AIF1CLK、释放 SAI 时钟，保留模拟准备状态；不再每个文件重走冷启动。无该回调的其他板保留原 reset 行为。
- 有未完成 DMA 时 idle 返回 EBUSY，避免提前关闭时钟。最终仍为 SAIEN=0、AIF1CLK=0、HPOUT1 静音，不宣称模拟电路全断电或释放持久设备 DMA 句柄。
- 新增首块提交到末块 DMA 完成的板端计时、总字节数；只更新固定统计字段，不改变 PDM 或共享 PLL。

## 2. 输出与格式、时钟

仍为绿色 CN9→WM8994 HPOUT1，SPKOUT关闭；没有调整连接。耳机输出不称独立 Line Out。原理图/BSP、ID=8994、7位I2C地址1a及引脚依据沿用 [硬件记录](../../../2026-10-21/bvo-04/README.md) 和 [初始化修复](../clock-lifecycle/README.md)。本次未更改输出连接或 GPIO。

标准路径仍是 NxPlayer→PCM WAV→WM8994→SAI2A→HPOUT1，音量15%，raw9，约-48dB。16kHz、16位有符号小端、双声道L=R，语音和测试音源不变。

PLL2P=25MHz/25×344/7=49142857.142857Hz，MCKDIV12、NOMCK0、OSR0：MCLK4095238.095238Hz、BCLK511904.761905Hz、FS15997.0238095Hz，误差-186.011905ppm。没有仪器频率实测。本版不再在停止后恢复默认48k，所以空闲分频仍可为12，但 SAIEN=0，不能把寄存器分频推算当成空闲时仍有时钟输出。

## 3. 样本与计时

为使主动停止有清晰时间窗口，增加 `/mnt/emmc/bvo04/tone-stop.wav`：将原1秒1kHz测试音PCM连续复制5份，只修改RIFF/data长度；仍为峰值2047、16k/16位/立体声。没有引入麦克风输入或隐式单声道转换。

| 文件 | 文件/PCM字节 | 帧数 | 板端本组计时 |
|---|---:|---:|---:|
| tone.wav | 64044 / 64000 | 16000 | 1000ms |
| speech.wav，yes | 64044 / 64000 | 16000 | 1000ms |
| tone-stop.wav | 320044 / 320000 | 80000 | 完整预检5000ms |

tone-stop主机参考SHA256：`7427082925602aedc972268afe01290f71b4bff7ed84b0d54b8dbb255fdd7522`。生成依据及格式见tone-stop.json，板端由vgaudio fixtures固定写入，未读回板端文件摘要。

计时粒度10ms，从首块提交到最后一次DMA完成，含提交/调度开销，不含精确的模拟输出起止或DAC滤波延迟；不能用它证明-186ppm频率误差。预检见preflight.log。

## 4. 最终固件验收

使用 `scripts/audio_accept.ps1 -RecordUnderruns`。这是显式诊断模式：默认严格验收继续遇欠载即停；诊断模式记录每个欠载值，继续收集启停/回归，结尾质量失败仍返回exit2，没有将其改为全项PASS。

最终结果见 accept-diagnostic.log、summary.json：

| 项目 | 结果 |
|---|---|
| 完整播放 | 20次，tone/yes交替；每次64000字节、8次DMA完成、板端1000ms |
| 主动停止 | 10次，使用5秒文件；只完成16340–32724字节，首块至末块DMA为250–510ms，均明显早于正常5秒结束 |
| 停止后重播 | 10次yes，每次64000字节、8次DMA完成、1000ms |
| 正常/停止后 | 每次快照SAIEN=0；最终HPOUT左右0009静音、AIF1CLK=0，无playthread/WM8994播放线程残留 |
| DMA/时钟错误 | TEIF/DMEIF计数0，timeouts0，clockerrors0；原始DMA标志仍有31，含FEIF，不能声称所有DMA标志均无错误 |
| 严格质量项 | 欠载快照计数26→156，仍失败；它是带粘滞位的DMA快照次数，不是130个独立事件。未证明全部与用户听到的轻微杂音同源 |
| TX边界请求 | 播放前后，无效接口、空长度、奇数长度、超容量、非法偏移各20次均返回预期结果，无新增异步完成 |

stop日志中的 bounded_wait_ms约2.3秒包含固定等待和状态查询，不是实际声音停止延迟；250–510ms是从首块提交到末块DMA完成，也不是从stop命令起算的延迟。人工已确认声音提前停止并可重播。

未故障注入DMA资源耗尽、真实DMA初始化失败或pthread创建失败；无效接口NULL、超APB容量-EINVAL不能替代这些路径，也没有从16位APB构造超65535半字传输的动态案例。
