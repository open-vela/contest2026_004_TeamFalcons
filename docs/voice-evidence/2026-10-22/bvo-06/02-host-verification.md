### 3.1 误识别与差异

| 现象 | 说明 | 影响 |
|---|---|---|
| 零一 变 零幺 | 同音字，TTS 音频回灌时出现 | 点位 ID 解析必须把幺归一成一，或直接按数字读音匹配 |
| `P 零一` 变 `P零一` | 英文与中文之间空格被去掉 | 解析时不能依赖空格分词 |
| 逗号变冒号 | 标点由模型生成，不完全对应原文 | 只做语义解析，不比对标点 |
| 句号变问号 | 疑问句自动加问号 | 不影响意图判断 |

本轮没有出现整句漏识、错字或串行。但样本是合成语音且只有 3 段不同文本，不能据此给出准确率数字。

## 4. TTS 调用结果

固定测试句：

- S1：测试内容，UPS 一号机输出电压二百二十伏，点位 P 零一当前告警。（34 字）
- S2：当前共有三项异常，分别是点位 P 零一温度过高、点位 P 零二离线、点位 MOD 三通讯中断。（47 字）

|---|---|---|---|---|---|
| S1 | wav | 冰糖 | 200 | 291884 | RIFF/WAVE，24000 Hz，1 声道，16 位，6.080 s，peak 21157，rms 3249，过零率 10.37% |
| S1 | wav | mimo_default | 200 | 268844 | 24000 Hz，1 声道，16 位，5.600 s，peak 25978，rms 3730 |
| S1 | pcm16 | 冰糖 | 200 | 322560 | 无头 PCM，按 24 kHz 单声道折算 6.720 s，peak 21750，rms 3484 |
| S1 | pcm16，流式 | 冰糖 | 200 | 307200 | 23 个 chunk，拼接后 6.400 s，peak 24011，rms 3933 |
| S2 | wav | 冰糖 | 200 | 399404 | 24000 Hz，1 声道，16 位，8.320 s |
| S2 | mp3 | 冰糖 | 200 | 65256 | 首字节 `ff f3 84 c4`，为 MPEG 帧同步；主机无 mp3 解码器，未解码 |

判定依据不止 HTTP 200：

1. WAV 用 Python `wave` 完整解码，帧数与字节数自洽。
2. 幅度统计非静音，峰值约 -3 dBFS 到 -1 dBFS，均方根约 -19 dBFS 到 -16 dBFS，与正常语音一致。
3. TTS 输出回灌 ASR 能复原原文，说明音频内容确实是人可理解的语音，可以排除噪声或空音。
4. 长句音频时长随字数增加，从 6.08 秒到 8.32 秒，比例合理。

未做人工听音。听音样本保存在 `raw/tts-s1-bingtang.wav`，可直接用系统播放器打开。建议在 BVO-11 联调时由操作者补一次听音，确认音色、语速和数字读法符合播报要求。

### 5.2 阶段拆分说明

- 请求准备（读文件与 base64）没有单独计时。按 480 KB 输入、base64 膨胀 4/3 估算，15 秒样本的字符串约 640 KB，主机耗时在几十毫秒量级，板端会明显更慢。
- 上传耗时与请求体大小成正比：640 KB 用时 18.45 ms，1.18 MB 用时 222 ms。家庭上行带宽波动会直接放大这一项。
- 非流式的首字节包含了服务端完整推理时间，无法再拆分模型加载与推理。
- TTS 流式的首字节只有 439 ms，但下载耗时 1534 ms，说明首个分片很快，后续音频按合成进度陆续到达。首包时间才是播报可以开始的时刻。

## 6. 对 30 秒预算的意义

按本轮数据，云语音部分的可观察耗时如下：

| 段 | 观测值 | 备注 |
|---|---|---|
| 录音后 ASR（15 秒音频） | 1.25 至 1.32 s | 含上传 |
| TTS 首包（流式） | 0.44 s | 短句 |
| TTS 完整音频（34 字） | 1.9 至 2.5 s | 非流式 |
| TTS 完整音频（47 字） | 2.9 至 3.2 s | 非流式 |

ASR 加 TTS 首包合计约 1.7 至 1.8 秒，完整 TTS 合计约 3.2 至 4.5 秒。剩余预算主要留给板载 Agent 的 ReAct 轮次，本轮没有测量，不能据此宣布 30 秒达标。板端的 TLS 握手、base64 编码、音频重采样都会比主机慢，实际余量更小。

## 7. 本轮未覆盖

- 真实用户语音、现场噪声、远场拾音下的识别率。
- 英文识别。
- mp3 输入。
- 24 位或浮点 WAV。
- 429 限流与重试退避的真实行为。
- 断网、DNS 失败、TLS 失败在板端的具体表现。
- 人工听音。
- 控制台账单与额度归属。
