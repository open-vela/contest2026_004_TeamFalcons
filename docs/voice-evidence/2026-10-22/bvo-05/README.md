## 当前结果

- 改为固定容量的独立 PDM 队列，滤波不再直接读取可能被 DMA 覆盖的半缓冲；记录并拒绝丢块结果。
- 补齐停止时的尾段；逐轮核对 PDM 字节、PCM 样本和时长。
- 开始与结束请求使用有界队列和代际绑定；快速命令开始/结束不会覆盖开始请求。按键结束绑定本次开始的代际。
- 停止检查 DMA/SAI 硬件应答；播放器停止使用有界消息发送和退出等待。停止失败时保留缓冲并禁止新录音。
- 修正把 WAV 写盘时间计入回放时限的问题，采用 16 KiB 批量写入。
- 主机测试、编译、烧录和命令级板测已执行，详见续接记录。

## 仍需满足的门槛

1. 在明确窗口取得 1、5、15 秒真实说话录音，并由操作者确认人声可辨、速度和时长正常。
2. 前置门槛通过后，执行至少 20 轮真实 USER1 录音到回放，以及至少 10 轮真实取消/上限工况，覆盖持续按住和释放门控。
3. 同步验证显示、触摸和听觉停止效果；当前无在线从站，不能证明正常读数。
4. 播放欠载与原有 FEIF 观察继续保留。本轮不把它们视为轻微杂音的一部分，也不宣称没有播放错误。
