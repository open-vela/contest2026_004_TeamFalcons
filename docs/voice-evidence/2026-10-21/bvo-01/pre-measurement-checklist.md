| M-01 | 麦克风通路 | `MP34DT01TR` CLK→PE5，DOUT→PE4，走 SAI4 PDM 直连，不经 WM8994 |

其中 M-01 推翻了方案初稿的采集路线推荐，M-03 暴露了 HPOUT1 与 SPKOUT 并联驱动同一插座的问题。两处的处理见方案文档第 5、6 节。

## 使用方法

本表已完成一轮实测，保留每节的原始判定方法作为复核依据。后续若更换板卡或怀疑接线，按以下顺序重测：

1. 先做 M-07（确认实物版本），其余条目的判定以实物丝印为准。
2. 再做 M-01，它是唯一阻断项，结果决定 BVO-03 走哪条采集路线。
3. 其余条目可以并行，不影响 BVO-01 文档提交，但影响 BVO-02 至 BVO-04 的代码。

所有测量在断电状态下用万用表通断档完成，除非该项特别注明需要上电。上电测量只用低压直流，不做热插拔。

## M-01 焊桥装配与麦克风通路

| 项 | 内容 |
|---|---|
| 待确认 | Audio 页 7 个焊桥（SchDoc 记录为 3 个 `SB_ON`、4 个 `SB_OFF`）的实际装配状态与位置对应；U34 的 `MIC_CLK`/`MIC_DATA` 实际连到 SAI4（PE4/PE5）还是 WM8994 的 DMIC 输入 |
| 背景 | SchDoc 可提取到焊桥类型与坐标（`SB_ON` 在 190,410 / 270,410 / 90,120；`SB_OFF` 在 230,410 / 130,390 / 370,260 / 90,160），但 SchDoc 文本不含连线拓扑，无法机器判断哪个焊桥控制哪条线 |
| 判定方法 | 第一步目视 Audio 页丝印位置，对照上面坐标定位焊桥；第二步万用表通断，测 U34 的 CLK/DATA 引脚到 PE4/PE5 与到 WM8994 DMIC 引脚的两条路径，确认哪一条导通 |
| 当前假设 | 未知。BSP 同时支持两条路径，不能据此推断本板实际装配 |
| 影响 | **阻断性**。决定 BVO-03 走路线 A（SAI4 PDM）还是路线 B（WM8994 DMIC） |
| 若假设不成立 | 按实测路线重写第 5 节取舍结论，并相应调整 BVO-03a 的范围（是否需要 SAI4 与 BDMA） |

**实测结果（2026-10-21）**：麦克风型号 `MP34DT01TR`，`CLK` 接 `PE5`，`DOUT` 接 `PE4`，即 SAI4 PDM 直连，不经 WM8994。

与假设是否一致：初稿推荐路线 B，实测为路线 A，**假设不成立**，方案第 5 节已按 SAI4 重写。BVO-03 需承担 SAI4 PDM 模式与 PDM 抽取滤波。

## M-02 绿色插座输出通道

| 项 | 内容 |
|---|---|
| 待确认 | 绿色 3.5mm 插座（SchDoc 标注 `Jack out Green`，坐标 1040,470）由 WM8994 的哪一路输出驱动：HPOUT1、SPKOUT，还是 LINEOUT1/LINEOUT2 |
| 背景 | NuttX `wm8994.c` 目前只启用 HPOUT1，SPKOUT 写死为关（`hp_out=1, spk_out=0`），LINEOUT 只有位定义没有启用代码。BSP 注释写只有一个输出设备 HEADPHONE |
| 判定方法 | 断电，万用表通断从绿色插座的 L/R 触点回溯到 U15 的对应引脚，对照 WM8994 数据手册确认引脚对应的输出通道。若通路中间经过跳线排针，一并记录 |
| 当前假设 | 未知。BSP 和 NuttX 驱动都暗示耳机路径，但未在这块板上验证过 |
| 影响 | 决定 BVO-04 是否要新增 LINEOUT 或 SPKOUT 的启用序列 |
| 若假设不成立 | 若为 LINEOUT，BVO-04 需要新增输出混音配置（`wm8994.h` 已有 `WM8994_LINEOUT1P_ENA`、`WM8994_DAC1L_TO_MIXOUTL` 等位定义可用）；若为 SPKOUT，需修改写死的 `spk_out` 值并评估 D 类功放的供电与时序 |

**实测结果（2026-10-21）**：绿色插座由 HPOUT1 驱动。

与假设是否一致：是。BVO-04 可复用现有驱动的耳机路径，不需要新增 LINEOUT 代码。但需与 M-03 一起看，见下一节。

## M-03 跳线排针用途

| 项 | 内容 |
|---|---|
| 待确认 | Audio 页两个 `Jumper Header 2x1`（坐标 860,270 与 860,300）的实际用途与出厂短接状态 |
| 背景 | SchDoc 只记录元件类型与坐标，没有网络名 |
| 判定方法 | 目视丝印与跳线帽位置，再用通断确认短接的是哪两个网络 |
| 当前假设 | 未知。可能是输出通道选择或测量点短接 |
| 影响 | 影响 BVO-04 的输出路由配置；若是通道选择跳线，还需在验收记录里写明板端实际跳线位置 |
| 若假设不成立 | 若跳线用于选择输出通道，BVO-04 的验收条件要增加跳线位置说明，避免换板后行为不同 |

**实测结果（2026-10-21）**：两处跳线分别把 `SPKOUTLN` 短接到 `LP`、`SPKOUTRN` 短接到 `RP`。

与假设是否一致：部分。跳线的功能是把左右扬声器输出直接接到插座的 L/R 触点，并非通道选择。

**这一结果引出初稿未预料的问题**：M-02 显示插座由 HPOUT1 驱动，M-03 显示 SPKOUT 也经跳线接到同一触点。两路模拟输出并联在同一负载上，同时使能会互相加载。VelaGuard 必须在软件上保持 `spk_out` 关闭。方案文档第 6 节记录了三种处理方式与推荐，BVO-04 的验收条件要覆盖这一点。

## M-04 蓝色插座输入

| 项 | 内容 |
|---|---|
| 待确认 | 蓝色 3.5mm 插座（SchDoc 标注 `Jack in Blue`，坐标 320,380，旁边有 Left/Right 文本）接入 WM8994 的哪个输入通道（IN1 还是 IN2），与 `MICBIAS1` 是否相关 |
| 背景 | `MICBIAS1` 网络在 SchDoc 里存在（坐标 150,150）。BSP 在模拟麦克风路径里用的是 `WM8994_IN_LINE1` |
| 判定方法 | 断电通断，从蓝色插座触点回溯到 U15 输入引脚 |
| 当前假设 | 未知 |
| 影响 | 只影响未来可能的模拟输入扩展，不影响本轮数字麦克风路线 |
| 若假设不成立 | 本项不阻断任何任务，仅记录 |

**实测结果（2026-10-21）**：蓝色插座接 `IN1LN` / `IN1RN`，与 `MICBIAS1` 无关。

与假设是否一致：部分。是 IN1 而非 IN2，且不涉及 MICBIAS。不影响本轮，仅记录。

## M-05 PC13 按键电平

| 项 | 内容 |
|---|---|
| 待确认 | B1（USER1/WAKEUP，PC13）按下与松开时的电平 |
| 背景 | BSP `BSP_PB_Init` 用 `GPIO_PULLDOWN` 加 `GPIO_MODE_IT_RISING`，即按下为高。NuttX `board.h:527` 注释误写 PI11 |
| 判定方法 | 上电，万用表或示波器测 PC13 对地电压，分别记录按下与松开 |
| 当前假设 | 按下为高，松开为低 |
| 影响 | 决定 BVO-02 的 EXTI 边沿方向与去抖逻辑 |
| 若假设不成立 | 若按下为低，BVO-02 改用下降沿并在 `GPIO_BTN_USER` 宏里改为上拉 |

**实测结果（2026-10-21）**：按下为高。

与假设是否一致：是。BVO-02 用 `GPIO_PULLDOWN` 加上升沿，与 BSP 及同族板样例一致。

## M-06 MICBIAS1 是否需要软件使能

| 项 | 内容 |
|---|---|
| 待确认 | U34 的供电是否依赖 WM8994 的 MICBIAS1，以及该偏置是否需要软件写寄存器使能 |
| 背景 | WM8994 上电默认 `SWRST=0` 后寄存器的默认值需要查手册；若 MICBIAS 默认关闭，采集前必须先配置 WM8994 |
| 判定方法 | 路线 B 时：上电后不初始化音频，示波器或万用表测 MICBIAS1 是否有电压；路线 A 时：同样测电压，判断是否需要额外使能 |
| 当前假设 | 需要软件使能 |
| 影响 | 决定采集初始化序列的第一步，影响 BVO-03 |
| 若假设不成立 | 若默认已使能，采集流程可省掉这一步，但仍建议显式配置以保证确定性 |

**实测结果（2026-10-21）**：不需要软件使能。

与假设是否一致：否，初稿假设需要使能。采集初始化可省掉这一步。由于麦克风走 SAI4 而不经 WM8994，MICBIAS1 与本轮采集路径无直接关系，本项实际已不构成约束。

| 判定方法 | 目视板边丝印版本号 |
| 当前假设 | B-01（依据原理图文件名） |

| 若假设不成立 | 若为 B-02，需核对音频页是否有差异；`readme.txt` 只记载了 LCD 与 eMMC 的变更 |

**实测结果（2026-10-21）**：B-01。

与假设是否一致：是。方案文档引用的 `mb1381-h750xb-b01-schematic.pdf` 与实物一致。
