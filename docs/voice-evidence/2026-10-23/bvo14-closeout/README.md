## 审查与实现

- Gemini 的 matrix-session 可复算为 23/30，文字正确 28/30；16 条播放结束时间超过 30 秒。30 秒口径是首次可播放。实际网络接口为 eth0，串口是开发入口，未取得 ESP8266 吞吐导致此次失败的证据。
- 跨线程事实捕获现在绑定 SDK 客户端、语音命名空间、请求序号、实际执行线程和配置代际。只接受该请求第一次发布的事实；后台、其他线程或旧请求不能填充当前回答。未捕获到匹配事实时仍经只读工具注册表补取，模型轮次保留。
- 模型后台请求增加受控取消，同时保留原始请求。语音 ASR 开始前暂停后台告警解释或日报，播报结束后恢复；旧回调按序号丢弃。主机用例验证恢复的是原请求，前台执行期间不能插入新的后台请求。真机覆盖必须看到实际暂停和恢复标记，单独出现后台任务不算通过。
- 已确认配置换代立即使运行态点位与事件历史失效，不生成虚假恢复。后续只接受当前配置代际的采样，HMI 的采集数组也带代际。删除后同名重加不能继承旧告警、旧读数或恢复时长。此处采用保守失效：任一确认表变更后，全部运行态历史重新积累。主机测试覆盖发布回调、换代、同名重加和旧写入拒收；未在板端自动确认或应用配置。
- 受控 HTTPS 上传将小的 WAV/base64 源片段合并为最多 16 KB 的 TLS 写入，堆缓冲有界且释放前清零；普通调用维持 4 KB。单测核对全部上传字节、部分写入、短源、非法源、取消与截止。IOB 512 曾提高吞吐，但随后出现云 TLS 验签失败，现做回退对照。
- TLS 会话恢复移入默认关闭的实验开关。关闭后仍复现过 RSA 验签失败，不能把根因归给缓存。未关闭密码学签名检查，也未接受校验失败的连接。
- 默认连接参数清空。历史 Git 对象与包含凭据的整份 AI 会话未删除或改写，仍由本人决定日志处理与凭据更新。

## 来源与分组

`capture_firmware.py` 记录镜像摘要、四个仓库 HEAD 和工作源码摘要，仅输出允许的配置项。每次烧录日志另存。

| 证据 | 范围和限度 |
|---|---|
| firmware-production / network-pilot | IOB 512 初次三问，三轮完成；ASR 约 4.3 秒，点查询首播约 21.7 秒 |
| firmware-diagnostic / handshake-regression | 会话缓存关闭后八次完整握手成功，固定无效凭据得到 401；不代表并发或所有云调用稳定 |
| preemption-cache-disabled、preemption-before-asr | 后台场景出现 RSA PKCS#1 验签失败；后者 ASR 与模型成功、TTS 失败，均保留为失败 |
| firmware-iob128-ab / pilot-iob128 | IOB 128 对照，三轮九次云握手成功；两轮完成，一轮模型耗时约 11 秒后 TTS 超时。计划内 NETWORK512 标记沿自原试跑，实际 IOB 以固件来源 JSON 为准 |
| scene-retry | 阈值与离线重叠不误恢复、事件环挤出后 history_complete=false、恢复为 recovered_partial。非空语音试跑失败，不能计为成功播报 |
| faults / fault-server | 整轮本地 HTTPS 故障矩阵，结果以自动检查文件为准；服务仅验证固定无效凭据，不记录头或音频 |
| host-tests-*、test_*-asan* | 分阶段主机全量回归及真实模块的地址/未定义行为检查；最初失败的编译和断言也保留 |

诊断故障入口仅在 `CONFIG_VG_VOICE_TEST_FIXTURE=y` 编译。只能选择固定的局域网端点或 `.invalid` 域名，使用专门的无效测试凭据，不读取真实密钥；一个目标故障只注入一次，TTS 重试恢复真实服务。普通 `bash scripts/build.sh` 自动退出诊断配置，来源脚本同时校验直接查询、实验会话缓存均关闭。

## 整轮故障与回收结果

`round-fault-summary.json` 记录 42 次尝试，其中 36 次具备完整证据，12 种故障各三次通过。其余六次也保留：夹具重启中断一例，串口元数据不完整两例，修复前坏 SSE 被分类为 net 三例。补测单独编号，没有覆盖或删除原记录。故障与元数据失败不计入固定 30 条延迟测试的分母。

ASR 覆盖 401、429、空文本、坏 JSON、HTTP 截断、错误域名及无响应；TTS 覆盖 401、429、HTTP 截断、坏 SSE 及无响应。ASR 失败显示错误，TTS 失败保留事实文字；结束后 `retained_pcm=0` 且受控请求已退出。无响应整轮错误提示约 30.5 至 30.7 秒，说明提示收尾仍可能略超网络预算，不能宣传所有错误路径严格在 30 秒内完成。

`tts-retry.log`：首次 TTS 429 后保留同一文字，仅重试播报成功；ASR 计数保持 7，TTS 从 7 增至 8。`record-limit-local.log`：合成按住超过 15 秒触发自动结束，实录约 14.93 秒，取消回收 130 ms，原始音频保留为零。该录音仅送到会丢弃请求体的局域网故障服务，不是人声或信噪比验收。

主机完整回归和新增运行态、真实云适配器 ASan/UBSan 通过。官方日志校验读取 307 文件、67,006 事件，结果为带一条 orphan 警告通过；未修改该历史会话或 manifest。
